# Sorbet — 소르베

[마리나라] 채팅 옆에서 외전을 이어 쓰는 미니 채팅방 확장 프로그램 (QR_Panel 확장판)

## 무엇을 하나

마리나라 채팅을 참고해서, 채팅은 건드리지 않고 그 옆에서 외전을 한 편씩 이어 써요. 짧은 AU를 이어 가는 미니 채팅방처럼 쓰면 돼요.
분석 · HTML 결과물도 만들 수 있고, 만든 결과는 보관함에 쌓여요. 마음에 드는 이야기는 채팅에 넣거나 새 채팅방으로 옮길 수 있어요.

QR_Panel 확장을 넓힌 판이에요. 따로 깔리고 데이터도 따로라 둘을 같이 써도 서로 건드리지 않고, QR_Panel 백업 파일은 소르베로 그대로 가져올 수 있어요.

## 설치

1. **Settings → Advanced** 맨 아래 **Danger Zone**에서 **Allow third-party extension imports**를 켜요. (처음 한 번만)
   - 스위치가 잠겨 있으면 서버 `.env`에 `ENABLE_EXTERNAL_EXTENSIONS=true`를 넣고 서버를 다시 켠 뒤 켜요.
2. `sorbet.json`을 받아 **Settings → Addons → External Extensions → Import Extension File**로 가져와요.
3. 검토 화면에서 **Full page access**를 확인하고 승인한 뒤, 페이지를 새로고침해요. 화면 오른쪽에 세로로 **소르베** 탭이 생겨요.

> `sorbet.js`를 가져오면 탭이 뜨지 않아요. 꼭 `sorbet.json`을 가져오세요.

## 쓰는 법

- **주방** — 양식을 고르고 주문을 써서 생성해요.
  - 분석: 인물과 관계를 읽어 줘요. 가정 질문도 돼요.
  - 스토리: 그 인물들로 독립된 한 편을 써요.
  - HTML: 휴대폰 화면 · 일기장 · 보고서 같은 결과물을 HTML 로 만들어요.
  - 자유: 정해진 지침 없이 쓴 지시문만 보내요.
  - 직접 양식을 만들 수도 있어요(지시문 · 입력칸 · 선택지).
- **픽업** — 막 끝난 결과가 모여요. 생성 중인 글도 바로 보여요.
- **보관함** — 모든 결과를 모아 봐요.
  - 결과를 열면 이어쓰기 · 다시 생성 · 부분 고치기 · 여러 편 합치기를 해요.
  - 본문을 더블클릭하면 그 자리에서 고쳐요. 설정 → 보기에서 끌 수 있어요.
  - 결과 수정에서 그 결과를 만든 주문 · 지시도 고쳐요.
  - 거르기 단추로 채팅방 · 양식 · 태그 · 폴더별로 걸러 봐요.
  - Ctrl+클릭 · Shift+클릭으로 여러 장 골라 폴더 · 태그 · 양식 바꾸기 · 삭제를 한꺼번에 해요.
  - 지운 결과는 휴지통에 30일 남아요.
- **양식** — 양식을 고치고 정리해요. 백업 단추로 전체 백업을 내보내고 가져와요.
- **설정 → 제목 짓기 → 다시 짓기** — 지금 채팅 결과들의 제목을 AI가 새로 짓고, 옛 제목 → 새 제목을 보고 고른 것만 바꿔요.

## 스킨 바꾸기

- **설정 → 스킨 → 스킨 프리셋** 에서 고르면 그 스킨이 커스텀 CSS 칸에 채워져요. **저장** 을 누르면 적용돼요.
  - 기본 스킨 7가지: 핑크 로맨스 · 다크 골드 판타지 · 모던 폰 · 네온 터미널 · 전술 HUD · SF HUD · 픽셀 일기장
- 프리셋 옆 **톱니(프리셋 관리)** 에서 내 스킨을 추가 · 편집하고, **추출** 로 파일로 내보내거나 **JSON 가져오기** 로 불러와요.
- **커스텀 CSS** 칸에서 직접 고쳐도 돼요. 불러오기 · 내보내기 · 기본값 단추가 있고, 칸을 비우고 저장하면 기본 모양으로 돌아가요.
- **설정창·편집기 창도 윈도우 CSS 따라가기** 를 켜면 설정 · 편집 창도 같은 색이 돼요.
- 스킨을 직접 만들거나 AI에게 만들어 달라고 할 때는 [SORBET_SKIN_GUIDE.md](SORBET_SKIN_GUIDE.md) 를 보세요. 바꿀 수 있는 이름과 AI에게 줄 요청 예시가 들어 있어요. 이 파일을 AI에게 주고 원하는 분위기를 말하면 스킨을 만들어 줘요.

## 필요한 것 · 알아 둘 점

- 롤플레이 · 비주얼노벨 · 게임 모드 채팅에서 써요. 대화(Conversation) 모드는 지원하지 않아요.
- 결과는 브라우저 저장소에 저장돼요. 브라우저에서 사이트 데이터를 지우면 함께 지워지니, 백업을 받아 두거나 서버 모듈을 쓰세요.
- **서버 모듈(선택)** — `server` 폴더에 있어요. 깔면 결과를 마리나라 서버에 저장하고, 창을 닫아도 생성이 계속 돌아요. 윈도 · 안드로이드(Termux) · 리눅스 · 맥 · 도커마다 설치 파일이 하나씩 있어서, 마리나라가 도는 서버라면 어디든 그 파일 하나로 깔아요. 자세한 순서는 `server/README.md` 를 보세요.
  - 따로 깔아야 하는 이유: 마리나라가 확장에 주는 저장소는 확장 하나당 1MB까지라, 쌓이는 결과물을 담기엔 작아요. 결과물까지 서버에 함께 저장하려고 소르베 전용 저장소를 따로 만드는 거예요. 또 마리나라는 브라우저 창이 닫히면 생성을 멈추기 때문에, 창을 닫아도 서버가 대신 끝까지 쓰게 하려면 서버 쪽 모듈이 필요해요.
- 채팅 메시지는 건드리지 않아요. 결과를 채팅에 넣는 것은 결과 화면에서 직접 '채팅에 넣기'를 누를 때만이에요.
- 채팅 정보(metadata)에는 그 채팅에 붙인 양식 목록(`srbAttachedForms`) 하나만 적어요.

## 안 될 때

| 증상 | 원인 |
|---|---|
| 소르베 탭이 안 보여요 | `sorbet.js` 만 가져왔거나 Full page access 를 승인하지 않았어요. `sorbet.json` 으로 다시 가져와 승인해요. |
| "서버에 생성 모듈이 없어, 화면을 끄면 생성이 멈춥니다" | 서버 모듈이 없을 때 뜨는 안내예요. 생성은 브라우저에서 그대로 돌아요. |
| "맥락 창이 모자라 채팅 대화 N개 중 최근 M개만 들어가요" | 연결의 맥락 길이에 비해 프리셋 · 로어북 같은 고정 내용이 커요. 맥락 길이를 늘리거나 고정 내용을 줄여요. |
| 분석이 지금 관계를 모르는 것처럼 써요 | 채팅 요약이 오래됐거나, 눈 감긴 대화가 많은데 요약이 없을 수 있어요. 마리나라에서 채팅 요약을 새로 만들어요. |
